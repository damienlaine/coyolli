# coyolli.com

Maquette du site Coyolli, bijoux mexicains faits main à Toulouse.

Site statique (HTML/CSS/JS, sans build), hébergé sur GitHub Pages.

- `index.html` — accueil
- `histoire.html` — l'histoire de Mariana
- `ateliers.html` — les ateliers partenaires, région par région
- `collection.html` — la collection (12 pièces d'exemple)
- `assets/` — logo, CSS, JS, images d'illustration (Unsplash)

Les photos sont des images d'illustration en attendant les photos des créations.
